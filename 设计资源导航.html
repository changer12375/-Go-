把这个清单分享出去

你加的和删的都只存在自己的浏览器里。想让别人也看到，下面两种办法选一种。

一 · 发个链接，对方打开就是一样的清单

你现在是直接双击打开的本地文件，这条链接别人打不开。按「说明」第三步发布到网上后，链接就能用了。

改动直接带在网址里，不用服务器。前提是这个站已经发布到网上（说明里的第三步）。

二 · 把清单写进文件，永久生效

粘进 html 里 const BUILTIN = [ 的末尾，再上传到 GitHub，所有打开的人都看得到。

怎么改成你自己的

一 · 不动代码也能改

右上角点「编辑」，每张卡片右上角会出现一个叉，点掉就是删。末尾会出现虚线框的「添加站点」，填名字、网址、一句话就能加进来。

加的和删的只记在这台电脑的浏览器里，换电脑不会带过去。

要让别人也看到，点右上角「分享」：要么生成一条带着清单的链接发过去，要么复制清单代码粘进文件里（走第二步），上传 GitHub 后就所有人都能看到。

这批站从优设导航（hao.uisdc.com）整站搬来：20 个一级分类、600 多个站点，按它的分类和子分类照搬，网址里的推广参数已去掉。带 logo 的 37 个是我自己一个一个打开确认过的，其余只核对过域名格式，没有逐个验证能不能打开。优设自己的「字体导航」里那 200 多个字体是它站内托管的详情页，不是独立网站，所以没搬；图书导航、色彩导航同理。

分类也能改：编辑状态下顶栏会多出一个「分类」，一级分类可以改名、上下移、加新的、整类删掉；点分类前面的小三角，还能改它下面的二级分类（改名、排序、加新的、整组删掉）。改完照上面一样分享出去，对方打开看到的就是同一套分类。

二 · 改内置清单

用记事本或 VS Code 打开这个 html，搜索 const BUILTIN = [，下面每行一个站点，照模板改引号里的字：

{c:"字体", s:"免费商用", n:"猫啃网", d:"免费商用字体汇总。", u:"https://www.maoken.com"},

c 分类，s 子分类，n 名字，d 说明，u 网址，顺序不能乱。加一行就粘在末尾，注意别删掉引号和行尾逗号。

三 · 免费放到网上

注册 GitHub（免费），点 New repository，选 Public 建仓库。

上传这个 html 前把文件名改成 index.html，否则别人打开只看到文件列表。

再到 Settings → Pages，Branch 选 main，Save。等一两分钟，拿到 https://用户名.github.io/仓库名/，永久免费。

改之前先把原文件复制一份存着，改坏了还能换回来。这个站没有服务器，所有改动都在文件和浏览器里。
